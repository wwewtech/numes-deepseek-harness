## Reddit post (suggested subs: r/DeepSeek, r/LocalLLaMA, r/AI_Agents)

**Title:** Free Numes models in DeepSeek Harness via a 0-dependency local proxy (`dsh plugin add` one-liner)

**Flair:** Show / Tooling

**Body:**

> Just published v1.3.0 of [`wwewtech/numes-deepseek-harness`](https://github.com/wwewtech/numes-deepseek-harness). It's a tiny zero-dep proxy that lets DSH use **[Numes's free `:free` model pool](https://numes.ai)** the way you'd expect: without surprise charges and without failures breaking sessions.
>
> **One-command install:**
> ```sh
> dsh plugin --profile desktop add github:wwewtech/numes-deepseek-harness
> node tools/numes-free-failover.mjs
> # → adds "Numes free (auto-failover)" to DSH's model list
> ```
>
> **The interesting bits:**
>
> 1. **Hard zero-cost guarantee.** Every model id must end in `:free`. Non-`:free` ids are rejected with 400 *before* any traffic reaches Numes. Plus `provider.max_price {prompt:0,completion:0}` is stamped on every request.
> 2. **Streaming-safe failover.** Tries the chain in sticky order (last successful first). If one model dies mid-stream, the response is abandoned, not mixed with the next model's tokens.
> 3. **Never-give-up retries.** When *all* free models are unavailable (which happens — free capacity is shared), it walks an exponential backoff `5s → 10s → 15s → 30s → 1m → 2m → 5m → ∞` and respects `Retry-After`. Aborts immediately on 401/402/403 (dead key) because retrying those makes no sense.
> 4. **Auto-discovery every 5 minutes.** `:free` catalogue is re-fetched; newly-free offers join the chain, removed offers are dropped.
> 5. **Zero deps.** One 410-line `.mjs`, Node 18+, no `npm install`. Reads the Numes key from `~/.dsh/.credentials.yaml` if you don't want to set an env var.
>
> **Why I built it:** Numes is genuinely useful as a free infernce catalog (the free tier is real and actually free — they explicitly guarantee no paid fallback). But free offers rotate, and the DSH built-in adapter doesn't auto-discover or back off. This is the smallest piece of glue that makes those two facts compose nicely.
>
> **[Repo + SETUP (EN/RU/中文)](https://github.com/wwewtech/numes-deepseek-harness)** — MIT, bilingual setup, runnable examples (curl/Python/Node/PS1), 7 integration tests in CI, hourly healthcheck optional.
>
> **Verified on DSH 0.2.2-rc.3.** Happy to take feedback in issues; not affiliated with Numes or DeepSeek.

## Hacker News – Show HN

**Title:** Show HN: 0-dependency proxy for free Numes models in DeepSeek Harness

**Number of comments expected:** low unless I post good first-comment answers.

**Body:**

> **Show HN: numes-free-failover** — a 410-line `.mjs` file (zero runtime deps, Node 18+) that wires [Numes](https://numes.ai)' genuinely free `:free` model tier into [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).
>
> Repo: https://github.com/wwewtech/numes-deepseek-harness
>
> **The problem.** DeepSeek Harness ships an OpenAI-compatible adapter (`llm-pi-ai`). Numes's catalogue lists some offers at $0 via the `author/model:free` suffix; the guarantee is no paid fallback. But the free pool drifts: a `:free` model can be removed minutes later. Polling `GET /models` once at startup is not enough.
>
> **The approach.** Refuse any non-`:free` id at request-parse time (400), cap every upstream request with `provider.max_price {prompt:0,completion:0}`, and refresh the `:free` catalogue every 5 minutes. On failure, walk the chain under `Retry-After`-aware exponential backoff. Abort on 401/402/403 (dead key, out of funds) because waiting is meaningless.
>
> **Test coverage.** 7 integration tests via `node:test` (boots proxy with a dummy key, hits the HTTP endpoints, asserts the guard rejects `moonshotai/kimi-k3.1-pro` and accepts the `:free` mirror). CI also runs the guard as a GitHub Actions step on every push, and there's an optional hourly live-call healthcheck that records cost per call.
>
> **Numbers.** Total proxy code: 410 lines. Test code: 110. No runtime deps. `node tools/numes-free-failover.mjs` boots with one env var and is ready in <200 ms.
>
> **Relationship to DSH.** It's an installable *bundle*. `dsh plugin add github:wwewtech/numes-deepseek-harness` registers a provider that points DSH at the local proxy. The proxy must be started separately (it's a long-running local server).
>
> **I am not affiliated with Numes or DeepSeek.** DSH Desktop 0.2.2-rc.3 + Numes USD free key verified; rc.4/rc.5 change unrelated behaviour.
